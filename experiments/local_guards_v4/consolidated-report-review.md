# Проверка сводного отчёта no-LLM

Независимый проверяющий в свежем контексте прочитал сводный отчёт, frozen CSV/
предсказания v3, confusion matrix v4 и LATENCY.md; исходные методы не запускал
и файлы не менял. Проверял соответствие цели частичного решения без LLM,
знаменатели, независимость тестов и интерпретацию стоимости.

Существенное замечание: доля определённых ответов не равна корректному
самостоятельному покрытию. По frozen predictions пересчитаны показатели:
v3 255/320; старые v1/v2 по179/320; LR86/320; CatBoost97/320; TF-IDF160/320.
Для полного v4: 291/400 корректных определённых решений при304 определённых
ответах. 94 остановленных нарушения включают92 BLOCK и2 UNKNOWN. Также
требовалось раскрыть11 BLOCK вместо gold UNKNOWN, помимо двух ошибочных ALLOW.

Замечание исправлено в одном проходе: основная таблица использует корректное
покрытие; STOP и определённый вердикт разведены, расхождения v4 перечислены.
Воспроизводящий experiments/summarize_no_llm.py выполняет прямой join frozen
gold/predictions и сохраняет полные confusion matrices в results/no-llm-summary.json.
Автор повторно выполнил этот пересчёт и проверил точное совпадение JSON.

Проверяющий подтвердил архивные знаменатели, разделение синтетики и архивов,
разные контракты v3/v4, раскрытие нарушения изоляции, UNKNOWN без передачи
защитнику и корректность приведённых задержек. Заключение: принять после
уточнения корректного покрытия и учёта UNKNOWN. Исправления внесены без
изменения методов, весов, разметки и исходных предсказаний; повторного review
после исправления не проводилось.
