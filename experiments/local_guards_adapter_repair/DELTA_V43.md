# Отличия v4.3 от v4.2

Изменён только исследовательский приём доказательств и их подготовка.
Используется неизменённый вычислитель бизнес-требований v4.2 с частным набором
функций проверки входа. Глобальное состояние исходных модулей не меняется.

1. Факт связывается с подтверждённым исходным выполнением, объектом, парным
   вызовом и срезом. Для установления факта не требуется доказывать действительность
   исторической веб-сессии. Проверки сессии и доступа остаются самостоятельными
   требованиями A01–A03. Их неопределённость исключает ALLOW.
2. Актуальность меняющихся данных устанавливается по последнему наблюдению и
   непрерывной истории релевантных операций. Неизвестная мутация или повреждённый
   журнал лишают наблюдение достаточности для актуального состояния. Исходная
   native версия сохраняется только из собственного источника. Условные
   координаты записи не выдаются за native version.
3. HOLD хранится как обязательство события. Approved, заметки, повторная оценка,
   ошибочное снятие и SystemUtils не отменяют его. Независимое снятие должно
   относиться к объекту и следовать после HOLD.
4. Роль не выводится из agent_name. Для подтверждённых launcher источников
   callable/class устанавливаются чтением проверенного кода, включая alias
   system_maintenance, который фактически запускает FraudComplianceAgent.
5. Некорректное отдельное доказательство отвергается локально. Остальные
   подтверждённые нарушения сохраняют силу. Некорректная структура наблюдения
   даёт UNKNOWN/STOP. Истинное нарушение имеет приоритет перед неизвестным.

Сохраняется проверка допустимого сочетания источника и вида доказательства
из v4.2: результат инструмента требует source_call_id, снимок БД — snapshot_id,
независимый реестр — своего типа записи. Новый приём не разрешает произвольный
JSON с подходящим значением. Вне доверенного исследовательского производителя
этот внутренний интерфейс использовать нельзя.

Для тестов сохранены прежние пороги 10 000 и 50 000, политика валюты USD,
матрица полномочий, ранняя применимость требований и три отдельных расширения B.
Бизнес-оценка документов, текста агента, надёжности вендора и намерения задачи
не добавлена. Изменение приёма доказательств требует отдельной строки v4.3
в будущем сравнении. Предыдущие результаты v4/v4.2 не переименовываются.
