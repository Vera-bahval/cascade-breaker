# Журнал подготовки scoring

При разработке прочитаны `inventory.json`, схема `custodian_manifest.json`, а также по одной строке из `results/historical-local.jsonl.gz` и `results/deepseek-historical.jsonl.gz` для проверки формата. Идентификаторы из custodian manifest использованы для фиксации хеша множества case ID. Текущая и прежняя разметки и их содержимое не открывались. Скрипт и искусственный тест созданы отдельно, сохранённые данные не менялись. Исполнены только unittest с искусственными данными и py_compile; подсчёт на исследовательских данных и вызовы моделей не выполнялись.
