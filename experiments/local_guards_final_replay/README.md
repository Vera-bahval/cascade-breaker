# Завершающий архивный replay FinBot

542 состояния P4 и их разметка зафиксированы коммитом
`36ee65526b29637602f066ce06d8e474e5fc4214`. Эксперимент повторно вызывает
замороженные локальные правила v1, v2, v3, v4 и v4.2. Для v4 используется основной
профиль A, в приложении показана также платёжная проверка A08. Ответы DeepSeek,
архивных правил и ML взяты из зафиксированных векторов.

## Данные и контракты

- В **общем режиме** распакован пользовательский пакет сохранённого запроса
  DeepSeek. Проверяются хеш запроса, содержимое пакета, P4, порядок, аргументы,
  происхождение события и сохранённый ответ. Все 542 состояния проверяются
  относительно замороженного консенсуса. В таблице выводятся отдельно
  недостаточный вход для двоичного правила, его собственный UNKNOWN и
  отсутствие проверенной пары.
- В **расширенном режиме** добавляются факты до действия с подтверждённой
  историей. [Реконструкция БД](EXPANDED.md) описывает исходную БД, задания,
  привязку к runner и причины оставшихся пробелов. [Проекции](PROJECTION.md)
  описывают преобразования для разных версий. Исходная политика v3 считает
  связанный успешный FLAG о запрете оплаты действующим до независимого снятия.
  Исторический FinBot допускает контекстную переоценку, поэтому такая
  блокировка может расходиться с исторической разметкой.
- **Условный технический replay** создаёт отдельную локальную запись
  тестовой сессии и связей вызовов для исходных данных. Выводы об этой среде
  показаны отдельно. Случайный идентификатор исторической сессии, историческая
  веб-аутентификация, человеческое разрешение и валюта счёта требуют
  собственных доказательств. SQLite работает только в изолированной копии.
- Старые v1/v2 получают состояние из исходного конструктора. Вызов v2
  включает исходное `enrich_state` на нормализованном префиксе. Для
  неполного входа приложение показывает доступность операндов без частичного
  вердикта. Время разделено на подготовку входа и решение. Показатели времени
  относятся к данному локальному replay.

## Ранние точки

[Отбор и границы префикса](EARLY_INPUTS.md) и
[протокол разметки](EARLY_RUBRIC.md) описывают восемь групп по 16 действий.
Оба раунда получили одни и те же слепые пакеты, а 44 случая с восстановленной
настройкой запуска получили одинаковое дополнение. Третий оценщик разобрал
расхождения итоговых меток. Исходные оценки и дополнения сохранены отдельно.
Terra оценивает допустимость конкретного действия по исторической политике.
В исследовательском контракте v4 более строгие проверки могут давать
дополнительные запреты или UNKNOWN.

Таблица качества относится к выборке действий, а симуляция первой остановки
к журналам 754 эпизодов. В режиме остановки только по BLOCK код продолжает
после UNKNOWN. В строгом режиме первое UNKNOWN тоже останавливает цепочку.
Статистика по всем наблюдавшимся точкам включает действия за первой
гипотетической остановкой. В отчёте они учитываются отдельно от достигнутых
точек. Даже ранний BLOCK перед P4 в записанной трассе сам по себе не
устанавливает предотвращённый ущерб или реакцию исполнителя.

## Воспроизведение

Из корня репозитория, Python 3.11+ с SQLite deserialize. Для пересчёта таблиц
достаточно опубликованных артефактов эксперимента и исходного PR.

```sh
exp=experiments/local_guards_final_replay
python3 -B -m unittest experiments.local_guards_final_replay.test_replay
python3 -B -m experiments.local_guards_final_replay.run_p4 --score-only --out "$exp/results/p4"
python3 -B -m experiments.local_guards_final_replay.run_early score \
  --early "$exp/early-data" --out "$exp/results/early" --ratings "$exp/ratings"
```

Для полного повтора извлечения и локальных прогонов нужны исходные архивы
четырёх моделей, база pristine C и закреплённые исходники FinBot в той же
структуре workspace, что указана в [описании источников](EXPANDED.md).
`early.py` принимает дополнительный путь к исходным архивам через
`--raw-root`. Сохранённые оценки Terra при воспроизведении читаются из файлов.

```sh
python3 -B -m experiments.local_guards_final_replay.run_p4 --out /tmp/finbot-p4-reproduced
python3 -B -m experiments.local_guards_final_replay.early --out /tmp/finbot-early-inputs
python3 -B -m experiments.local_guards_final_replay.run_early predict \
  --early /tmp/finbot-early-inputs --out /tmp/finbot-early-reproduced
python3 -B -m experiments.local_guards_final_replay.run_early score \
  --early /tmp/finbot-early-inputs --out /tmp/finbot-early-reproduced --ratings "$exp/ratings"
```

Времена локального прогона зависят от машины. При сверке реплики сравниваются
состояния, вердикты, причины, требования и доказательства. Манифесты
сохраняют SHA-256 входов и записанных выходов.

Опубликованный набор для пересчёта ранней таблицы содержит координаты событий
и признак наблюдаемой попытки перевода. Полные слепые пакеты и нормализованные
журналы воспроизводятся из исходных архивов. Сохранены их контрольные суммы.
В опубликованных подтверждениях банковские и контактные идентификаторы
заменены хешами, а пути к архивам указаны относительно workspace.
