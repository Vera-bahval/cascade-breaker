# M2-SAFETY: constraint propagation without promoting advice (5 x 6 continuations)

Часть отчёта [«Охранники и восстановление ошибок в FinBot»](../README.md). Здесь — данные и код, на которых стоят числа
отчёта; сырые трассы прогонов, SQLite и журналы вызовов хранятся локально и в репозиторий не входят.


**Сырые данные.** `raw_manifests/*.sha256.csv` — путь, размер и sha256 каждого файла локального архива (M2-SAFETY: 326 файлов). По ним можно проверить, что архив не менялся.

Тексты отчётов — рабочие версии на момент эксперимента; пути в них относительны корню локального проекта.
