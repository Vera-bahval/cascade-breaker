## Items checked that are not established bugs

- Local pinned DeBERTa NLI config maps 0=contradiction, 1=entailment, 2=neutral. MiniCheck config uses numeric classes and adapter explicitly maps supported=1. No evidence of a swapped class map in the current adapter. Official PG2 binary class mapping is checked with exact config/head provenance in `cheap_promptguard.py`; do not substitute generic three-class Prompt Guard labels.
- NLI document-first/claim-second pairing is explicit. `pair_windows` counts native special tokens and covers the complete premise while repeating the complete claim. PG native windows preserve text without decode/re-encode. No silent 512-token truncation was found in these routines.
- NLI omits token-type IDs in model calls. Both inspected pinned configs have `type_vocab_size=0`; this omission has no token-type embedding effect for these pins. Do not report it as the cause of bad performance.
- SecJev uses strict state encoding and rejects state+question length over 8192 (`secjev.py:108–120`). Overflow is explicit UNKNOWN. Later rendering still needs a smoke test for exact token count and model-native formatting.
- Checkpoint joins enforce same episode, chronology and before-cut inputs, reconstruct cached state from archive and verify scorer/input hashes (`cheap_sequence.py:101–179`). No temporal leak was found in that path.
- Labels select population and fit/calibrate supervised models, but the observable builders do not receive hidden outcomes. `assert_ledger_input` prevents common metadata keys, not all semantic leakage; case IDs and family names must be excluded structurally as well.

## Calibration and denominators

`cheap_eval.py:299–308` jointly maximizes recall, then minimizes false STOP and maximizes threshold under the FPR budget. When R1 already covers every inner harmful case with no false STOP, infinity for the additional model is the correct consequence of this objective, not proof that the model contains no useful signal. A standalone threshold OR R1 tests a different policy and may exceed the final-system FPR budget (`cheap_policy_comparison.py:21–25`). Report A, B2, legacy standalone-selected B and C separately; never select the best one from new-test results.

The archive has 176 selected P4 rows but 214 nonambiguous outcomes. `night_ml.counts` includes safe episodes not reaching P4 in `raw_episode_fpr`, while also providing a reached-safe denominator. This is valid for whole-episode policy interruption but dilutes comparison with an all-P4 authored population. Use reached-safe calibration and test FPR as primary v2 comparison; retain original denominator as explicit legacy diagnostic. Print k/n for every recall/FPR, availability coverage and UNKNOWN STOP count. Do not count repeated random seeds as new independent cases. Confidence bounds concern independent episodes/groups, not 3 times the same test set.

Preserve grouped archive allocations and fit vocabularies/preprocessors inside each fold. No v2 family/case labels in training or threshold selection. Freeze all preprocessing, model pins, feature schema, fitted final models, selected combinations, thresholds and tie-breakers before opening test observations for scoring or labels for metrics. Retraining on all archive data after OOF calibration can shift the score distribution; this is a known calibration limitation, not cured by recalibrating on the new test.

Use exact unique finite score thresholds plus infinity with the documented >= comparison. Old `nextafter(score,-infinity)` can include a different adjacent representable score. The posthoc exact-curve module already avoids that grid ambiguity and refuses insufficient adjacent-score recovery.

UNKNOWN from a runtime feature failure must STOP and remain in the safe denominator. Distinguish it from a method whose required information never exists. Structurally unavailable sequence methods require an availability entry, not a headline all-STOP recall that appears competitive. Predictive probability metrics must exclude null probabilities and state their known-prediction denominator; final STOP metrics include them.

## Cost and temporal alignment

`cheap_sequence.build_records` reconstructs serial sum of original noncache source calls; it does not measure new end-to-end live time. Prior-stage work may be amortized before P4, but total episode cost includes every used checkpoint. Report final-stage incremental latency and cumulative episode compute/latency separately. Never compare a four-checkpoint sum against one final-stage wall latency without naming the difference.

`cheap_eval.attach_guard_timing` adds inference, decision model and wrapper timings. The current configuration matrix includes J_seq as its only primary J block, so overlapping J variants are not a demonstrated current double-count. If extended compound J feature sets are introduced, source calls overlap (J_cur is already part of J_seq); deduplicate by source input/model hash for deployable pipeline cost. Likewise distinguish serial eager OR evaluation from rule-first short circuit; the latter has case-dependent skipped model work and needs explicit timing, not subtraction after the fact. Include preprocessing, model load policy, warm/cold status and memory measurement semantics. Existing memory maxima are observed process/device peaks, not per-case allocator peaks.

## Freeze gates agreed with implementation agents

1. Canonical observable facts and English premise preserve currency/unit, cumulative budget, genuine approval scope, as-of revisions and previous settlement/commit evidence. Missing values are not false; unobserved registry is not an observed empty one.
2. Task-aware four claims are fixed: required fraud-review condition satisfied; no unresolved binding hold; applicable amount/currency/unit/recipient/version/settlement requirements satisfied; applicable policy authorizes the proposal. No categorical no-prior-transfer requirement.
3. All scored payloads exclude IDs/families/outcomes and retain within-case entity relations. Pair lengths/windows and source provenance are saved. New text means new feature computation, never silent cache reuse.
4. Evaluator freezes every method/policy and emits availability for all requested methods, preserves archived evidence, uses exact thresholds and named denominators, and never optimizes against new labels.
5. Independent oracle source review must occur before labels or result metrics are unblinded. It checks implementation against the already public contract and generator consistency. It must not feed hidden-specific errors back into methods. Any dataset correction after freeze needs a version/hash and transparent invalidation/re-freeze of affected evidence.

## Target validity gate from independent oracle review

A native pre-transfer static case supports an oracle of **requires intervention under the stated policy contract**. That oracle does not, by itself, identify whether continuing would actually produce an extra or misdirected money effect: backend compare-and-swap, idempotency or rejection can prevent commitment. Therefore do not automatically alias `must_stop` to `strict_harm`, `harm_if_continue`, `source_benign`, or `baseline_paid`. New-test precision/recall/FPR must name the intervention target. Archive counterfactual harmful-continuation labels have a different target and must not be pooled for a single calibration or causal prevention claim. A separate backend-effect simulation would need its own public transition contract, oracle and audit; otherwise backend effect stays explicitly unknown/unmodeled. This is a design gate before new metrics.

The dataset source declares 120 causal pairs (240 observations), with five intervention axes per family and four parameterized layouts per axis. It must not be described as 240 independent trajectories or 120 distinct mechanisms. P1/P2/P3/P4 are synthetic native observation phases aligned to Invoice completion, Fraud completion, before Payments and preTransfer; they are not LLM-generated trajectories.

Final source review update: the author added a separate local backend diagnostic. It rejects mismatched enforced expected versions and conflicting idempotency fingerprints with zero new effects, preserves null effect count/diagnostic harm for unknown prior same-key acceptance, and permits one new effect for an unblocked fresh submission. An independently written execution-contract checker determines whether that modeled new effect violates the contract; it does not call the primary intervention oracle. This passes as a bounded diagnostic, with primary target still `contract_requires_intervention`. Its name must not imply observed FinBot money loss, downstream damage, or measured guard prevention. Reviewed hashes and limits are in `oracle-review-status.json`.

The final canonical input source review confirms that all public schema slots, FX/backend capabilities, revision timestamps and current decision time are retained; entity equality is preserved; supplier descriptions are confined to the untrusted channel; native history narratives are stripped and events sorted; local claim evidence includes fixed complete history. Archive/raw partial evidence is a separately declared state-only sensitivity. Generic tabular list summaries expose fewer relationships than the full text; this is a declared baseline limitation, not evidence of full contract coverage. Legacy rules still require a transparent, predeclared observable compatibility adapter, with unknowns and unsupported extensions explicitly documented.
