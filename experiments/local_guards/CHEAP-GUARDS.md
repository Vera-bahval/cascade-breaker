# Динамика Jev, Prompt Guard 2, NLI и MiniCheck

Новая архивная серия не перезаписывает ночную 4B-серию. Основной протокол:
`results/cheap-guards/protocol.json`; начальный deadline сохранён в `run.json`
и не сбрасывается при возобновлении. Платные inference API и живой FinBot не
используются. HTML: `reports/cheap-report.html`.

## Данные и признаки

Те же 176 P4-префиксов и 214 неамбивалентных эпизодов: 83 опасных продолжения,
131 безопасное, из них 93 достигли P4. Исходно честных задач 98 — это отдельная
популяция. Политика HOLD и разметка сохранены; прежние правила и модели неизменны.

Последовательность SecJev 0.8B восстанавливается по четырём этапам внутри эпизода:
Invoice, Fraud, передача Payments, перед переводом. `J_cur` — 4 текущие оценки;
`J_seq` — 16 оценок напрямую; `J_agg` — 20 признаков текущего состояния и агрегатов;
`J_dynamic` — 48 признаков последовательности, разностей и агрегатов;
`J_prior` — 12 оценок до P4. Нового inference 0.8B нет. Время чтения кеша не
выдаётся за стоимость мониторинга: последняя реконструируется из исходных вызовов.

Для NLI/MiniCheck отдельно измеряется минимальный скалярный вариант: четыре
фиксированных утверждения против доверенных объединённых фактов. Адаптер
`cascade_guard.cheap_scalar:create_adapter` сохраняет исходный input hash;
равенство скаляра полному извлечению проверяется на всех 176 примерах с допуском
1e-4. Файлы `scalar-profiles/N.jsonl` и `M.jsonl` служат только для оценки
стоимости, не становятся новыми признаками или кандидатами выбора. Полная
таблица комбинаций использует исходные полные извлечения признаков.

Prompt Guard получает только недоверенный invoice и публичные утверждения
агентов. Официальные веса Meta требуют одобренного доступа. Вход в браузере сам
по себе не предоставляет доступ CLI; cookies и токены из браузера не извлекаются.
Неполученные веса отмечаются как зависимость, без подмены checkpoint.
После отказа HF пользователь отдельно поручил найти файлы вне HF. Проверенные
копии получены из ModelScope: официальные pinned LFS SHA-256 весов и Git blob ID
остальных runtime-файлов полностью совпадают; это те же checkpoint. Доказательства,
точные URL/ревизии зеркала и фактические локальные checksum находятся в
`results/cheap-guards/promptguard/`. Команда скачивания и её исходник сохранены;
зеркало не становится новым model ID. Пустая таблица label names официального
config обработана отдельным amendment до PG inference: бинарное соответствие
0=BENIGN/1=MALICIOUS подтверждено закреплённым исходником Meta и реальными
размерностями классификационной головы. Входы и определения признаков сохранены.

NLI/MiniCheck проверяют четыре фиксированных утверждения и предложения объяснения.
Политика, нативные факты с происхождением и недоверенные заявления разделены.
Поддержка заявления invoice не считается доверенным разрешением. Все окна
обрабатываются полностью с перекрытием 64 токена; переизбыток длины утверждения
или ошибка модели возвращают UNKNOWN. Пустой естественный канал имеет mask и
sentinel -1; это не нулевая вероятность атаки. Полные распределения сохранены.

## Воспроизведение

Из корня workspace, без запуска моделей:

```sh
PYTHONPATH=experiments/local_guards experiments/local_guards/.venv-finbot/bin/python \
  -m cascade_guard.cheap_sequence --help
PYTHONPATH=experiments/local_guards experiments/local_guards/.venv-finbot/bin/python \
  -m cascade_guard.cheap_inputs --help
```

Модельный runner требует явного `--resource-lease` и межпроцессной блокировки.
Только одна загруженная модель, FP32. CPU и MPS проверяются на шести коротких/
длинных входах по три раза; MPS допускается при разнице не выше 1e-4, без смены
класса. Иначе используется CPU. Веса, зависимости, входы и исходники привязаны
к revision/checksum. `scripts/run_cheap_models.py --help` показывает точные
аргументы; deadline брать из существующего `run.json`, а не назначать новый.

После окончания всех model worker:

```sh
python3 experiments/local_guards/scripts/finish_cheap_series.py
```

Финализатор проверяет исходные результаты, фактические байты весов, входы и
исходники; выполняет оценку, проверки и генерацию отчёта. Межпроцессная блокировка
не позволяет запустить его одновременно с model worker. При исправлении только
проверок или отображения после успешно законченной оценки используйте
`--resume-postprocessing`: ранее выполненное обучение повторяться не будет,
если его входы, код и выходы сохранили checksum. Deadline остаётся прежним.

Отдельные команды оценки:

```sh
PYTHONPATH=experiments/local_guards experiments/local_guards/.venv/bin/python \
  -m cascade_guard.cheap_eval --records \
  experiments/local_guards/results/cheap-guards/sequence/features.jsonl \
  experiments/local_guards/results/cheap-guards/models/N.jsonl \
  experiments/local_guards/results/cheap-guards/models/M.jsonl --freeze-only
```

Добавить полные файлы G22/G86, если официальные веса доступны. Для оценки заменить
`--freeze-only` на `--run`. Дополнительный raw64 подключается через `--raw-records`,
`--raw-rows`, `--raw-labels`; не использовать raw-метки для обучения или порогов.
Неполные файлы не объявлять полными моделями. Финальная серия сохраняет точную
исполненную команду отдельно в manifest выполнения.

## Оценка и границы вывода

Outer3/inner2 групповых разбиений и seeds17/29/43 совпадают с ночной серией.
Порог и комбинация выбираются только на обучающей части. Проверяются все
непустые комбинации доступных J_seq/G22/G86/N/M, с табличными признаками и без,
каждая без rules, с исходными rules и с замороженными rules_v2. CB200/depth3/
lr0.03/L2=5; параметры не подбираются. Rules_v2 ранее разрабатывались с учётом
архива и не являются нетронутым научным контролем.

UNKNOWN останавливает эпизод, но не превращается в p=1. Brier/log loss/PR-AUC
относятся к обученному компоненту до переопределения rules. Выходы атомарных
классификаторов не являются вероятностью вреда. Три seed повторно делят одни
эпизоды; их нельзя суммировать как независимые наблюдения. Результат —
контрфактический STOP, не живое предотвращение.

Raw64 — уже известный синтетический стресс-тест. Для него нет четырёх Jev
checkpoint и части исходных табличных признаков. Такие конфигурации явно
неподдерживаемы; полный победитель и отдельно выбранный на архиве raw-совместимый
победитель не подменяют друг друга. Модели и пороги фиксируются по архиву до
подсчёта raw-метрик.

## Калибровка и дополнительные проверки протокола

Внешний аудит выявил структурный потолок совместной калибровки: все пять пропусков
R1 принадлежат одной группе. Когда она удержана, R1 покрывает все обучающие harms,
и критерий min FP/highest threshold выключает дополнительный детектор. Историческая
серия выбирала lowest feasible threshold, поэтому её числа — отдельный reference.

`matched-reference/` воспроизводит 4B с новой калибровкой по прежним 528 оценкам;
формат выбирается внутри обучения. Основные 747 оценок не изменяются. Для нового
контрольного запуска используйте общий внешний lock и исходный deadline:

```sh
python3 experiments/local_guards/scripts/run_cheap_reference_serial.py --freeze-only
python3 experiments/local_guards/scripts/run_cheap_reference_serial.py
```

Замороженный reference CLI из выполненного запуска имеет собственный ошибочный
путь lock в `local_guards/.runtime`; фактически запуск был последовательным по
координации исполнителя. Его код и manifest сохранены. Новый launcher выше
добавляет правильную внешнюю блокировку workspace и ограничение первоначальным
deadline. Напрямую reference CLI для параллельных запусков не используйте.

`protocol-diagnostic/` — явно post-hoc диагностика, зафиксированная отдельным
планом до её вычисления: существующие решения компонента `:none` объединяются с
R1. Никаких новых моделей, fit, порогов или выбора по внешним результатам:

```sh
PYTHONPATH=experiments/local_guards experiments/local_guards/.venv/bin/python \
  -m cascade_guard.cheap_protocol_diagnostic --freeze-only
PYTHONPATH=experiments/local_guards experiments/local_guards/.venv/bin/python \
  -m cascade_guard.cheap_protocol_diagnostic
```

Это дополнительное объяснение ограничения основного протокола, не его замена.
Итоговые выводы находятся в `results/cheap-guards/findings.md`.

Обновить HTML без повторения inference или обучения:

```sh
PYTHONPATH=experiments/local_guards experiments/local_guards/.venv-finbot/bin/python \
  -m cascade_guard.cheap_report
```
