# REPRESENTATIVE_ACTUAL_HOOK

Основной P4-срез содержит 542 actual before-tool hook. Удалены только пять P4 model-proposal состояний по замороженному source_event_kind; все 749 P2 и 754 эпизода сохранены. Прежние расширенные таблицы на 547 P4 не изменены.

P4: 232 исходно размеченных состояния (147 ALLOW, 85 BLOCK), 310 неразмеченных; native core: 12 BLOCK, 526 ALLOW, 4 UNKNOWN. Достигнуты 112 исторически добросовестных задач. Полный знаменатель 846 здесь не используется как гибридная FPR.

Correct означает совпадение с исходной целью сценария, а не полную native-допустимость действия. Известный текущий HOLD определяется только замороженным вектором native BLOCK с причиной N09:current_typed_hold. Обход означает локальный маршрут ALLOW без DEFER на данном срезе; решений по произвольному тексту и новых семантических правил нет.
