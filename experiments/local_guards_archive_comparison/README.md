# Archive-first no-LLM comparison

[Основной отчёт](../NO_LLM_REPORT.md) · [Техническое приложение](REPORT.md) · [Аудит](provenance/final-audit.md)

Эксперимент сравнивает методы на сохранённых реальных исполнениях FinBot. Нативная политика, исходное ожидание задачи и исход продолжения являются разными осями. Глобального победителя по «безопасности» не выбирали. Все опубликованные варианты, включая отрицательные и несовместимые, сохранены.

## Артефакты

- `data/historical/observations.jsonl.gz`: полные начальные сведения и префиксы, без будущих результатов. Финальная БД не используется для достраивания входов.
- `data/technical-context-patches*`: только три явно объявленных технических поля. Восстановленный второй режим должен совпасть с первоначальным hash; новых финансовых фактов нет.
- `data/split-*`, `data/evaluation-metadata.jsonl.gz`: группировка, точный seed17, исполнители, разбиения и связи с исходниками.
- `labels/`: раздельные структурные/source-ожидания и проверенные outcome receipts. Имя `actions-unreviewed` историческое; разрешение использования дано отдельными `labels-clearance` и `oracle-recovery-clearance`.
- `results/ml-release-v2/`: 12 весов, параметры, TRAIN-препроцессинг и замороженные CAL-ответы. `ml-release-failed-csr-int32` — сохранённый незавершённый fit до поправки транспорта матрицы, не результат для сравнения.
- `source-freeze*`, `results/*freeze*`, `inference/freeze.json`: последовательность фиксации методов, данных, параметров и выбранных запросов.
- `results/*local.jsonl.gz`: неизменные локальные прогнозы; `results/deepseek-historical*`: присоединённые ответы защитника.
- `results/eliza-run/`: точные уникальные requests/responses, сопоставления case→query, фактические списания и квота. Секретов авторизации здесь нет.
- `results/*score.json`, `results/cascade-*`: все знаменатели, групповые интервалы, парные различия и маршруты первого STOP. Сложная выборка не используется вместо представительной.
- `adjudication/`: отдельная слепая модельная разметка реальных действий после фиксации методов. Она не использовалась для обучения/выбора порогов и не является human gold.
- `provenance/`: журналы чтений, исходные ошибки подготовки и их исправления до fit, независимые проверки и явные ограничения.

## Локальное воспроизведение без API

Нужен полный Git checkout с объектом `ec93a1bebc829c5e502e3876e8415edc4fe12a4b` для неизменного старого constructor. Зафиксированные версии Python/пакетов находятся в [environment.json](environment.json), минимальные библиотеки анализа — в [requirements-reproduce.txt](requirements-reproduce.txt). Native replay дополнительно использует зависимости текущего `finbot/` и проверяет их фактически загруженные исходники.

Из корня репозитория, в отдельном checkout, с установленным окружением:

```sh
python -m experiments.local_guards_archive_comparison.verify \
  --local-predictions --receipt /tmp/archive-reproduction.json
```

Команда не вызывает API и не переобучает модели. Она проверяет исходники/веса, восстанавливает технический режим из маленьких patches, заново строит общую проекцию и TRAIN/CAL-копии, проверяет идентичность развёрнутых сведений всех фактически отправленных запросов, затем повторяет каждый локальный вердикт и вероятность. Временная общая проекция удаляется. Игнорируемые воспроизводимые кэши могут появиться заново. Исходные отчёты, веса, прогнозы и manifests не перезаписываются.

В замороженных manifests сохранены абсолютные пути первоначального стенда. `verify.py` переносит только пути ссылок в памяти, проверяя те же содержательные SHA; источники и данные не переписываются. Локальные времена не обязаны совпадать на другой машине. Повторный fit CatBoost может иметь другой бинарный metadata hash; при проверке сохранённых весов требуется точный hash, при независимом fit сравниваются также признаки, параметры и прогнозы.

Отдельные стадии при необходимости:

```sh
python -m experiments.local_guards_archive_comparison.canonical_dataset
python -m experiments.local_guards_archive_comparison.views
python -m experiments.local_guards_archive_comparison.release
python -m experiments.local_guards_archive_comparison.technical_replay --help
```

`views`/`release` в свежем корне могут обновить пути в своих воспроизводимых metadata-копиях; используйте изолированный checkout и не заменяйте ими опубликованные freezes. Проверка `verify` сохраняет опубликованные manifest bytes.

Локальный повторный fit выполняется в **новом** каталоге через `ml.fit_release`, с шестью gzip TRAIN/CAL-пакетами из `packages/release`. Их точные hashes опубликованы в fit/readlog и frozen model manifest. Нельзя повторно обучать на CAL или смешивать selected/Luna с TRAIN. Параметры и seeds17/29/43 менять в рамках этой оценки нельзя. Для повторения оценок используйте `evaluation freeze/predict/score --help` и команды в [отчёте оценщика](provenance/evaluation-implementation.md); свежий freeze/receipt создаётся отдельно, исходный не редактируется. Новых ответов DeepSeek для локального воспроизведения не требуется.

## Проверки реализации и исполнения

```sh
python -m unittest discover -s experiments/local_guards_archive_comparison/tests -v
```

Часть тестов использует текущий FinBot, сценарный клиент и временные БД. Это API-free проверка настоящих перехватов, не архивная точность и не адаптирующаяся LLM. Старый timed replay сохраняет прежний hash неиспользованного ML-файла; текущий тест native-only пути явно инъектирует неизменный guard после проверки его SHA. Исполнение новых ML callbacks измерено отдельно в `benchmark.py` с актуальными весами. Старые source receipts не переписаны.

Последние проверенные команды и их результат фиксируются в `provenance/verification.json`. Прежние v3/v4/v4.2 payloads сверяются с `baseline.json`; изменение основного отчёта разрешено заданием. Согласованная отдельная ML-ревизия: `fc181fe0212846ec7c0f0ef71358d2c9ed13a40b`, её дерево сохраняется без изменений.

## Границы интерпретации

UNKNOWN останавливает самостоятельное исполнение, но не считается обнаружением или решением. В предкаскаде DEFER вызывает защитника; отсутствие обязательного факта даёт STOP_UNKNOWN. Сэкономленный вызов с UNKNOWN не является корректно решённым случаем. Предкаскад, который обходит актуальный HOLD, не получает право называться безопасной заменой только из-за меньшего числа запросов.

Новая закрытая проверка обобщения, реальный банковский перевод, production atomicity и поведение адаптирующегося FinBot здесь не измерялись. API-MAST — открытый каталог сценариев по таксономии сбоев. Старые искусственные состояния остаются regression-тестами реализации.
