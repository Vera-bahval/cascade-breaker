# Уточнения после ревью PR #5

Результаты моделей на сохранённых эпизодах не изменились. Исправлены пересчёт,
проверки полноты и подача стоимости и времени. Новых обращений к моделям нет.

| Замечание | Что изменено или уточнено |
|---|---|
| Числа в тексте отчёта заданы вручную | Результаты во вводном тексте, размеры выборок, расходы, прогнозы и число запросов берутся из данных пересчёта. Фиксированными остаются условия протокола и историческая цитата о расхождении mini. |
| Main DeepSeek не совпадает с billing proof | Это разные охваты: main стоит 4.403506026 USD, smoke и пилоты 0.227548410 USD, все фазы 4.631054436 USD. Теперь суммы считаются из запросов и автоматически сверяются с billing proof, включая число оплаченных ответов. |
| Знаменатель FPR задан как 150 | Оба счётчика читаются из summary; тест использует другой знаменатель. |
| Верхняя оценка Luna смешана с фактическими расходами | API-эквивалент вынесен в отдельные строки. Сохраняются обе границы; для известных запросов они совпали. Расход четырёх запросов остаётся неизвестным. При разных границах одна сумма не подставляется вместо интервала. |
| Отсутствующее поле защитника становится false | Используется трёхзначная логика. Известное срабатывание даёт true; false с отсутствующим результатом остаётся неизвестным. Неполная метрика не выдаётся за 0/N. |
| Нет boundary-представлений, но стоимость и время равны нулю | Неполные проверки получают null и исключаются из распределений. Покрытие указано явно. Ноль остаётся допустимым для детерминированных правил без запросов к модели. |
| Сумма длительностей голосов выглядит как задержка | Поле переименовано в query_duration_sum_s. Отдельно приведена оценка параллельного запуска трёх входных голосов, без утверждения об измеренной задержке системы. |
| Число эпизодов не исключает подмену пропуска дублем | Проверяются уникальные ключи dataset, scenario_id, repeat и точное множество ожидаемых ключей, включая все повторы Веры. |
| Ревизии в упаковщике читаются из текущего каталога | Все три git rev-parse выполняются с -C source. Тест запускает проверку из другого репозитория. |
| Не все сжатые индексы и карты защитников очищаются и проверяются | Единый проход по всем JSON и JSON.gz в inputs; валидатор проверяет инвентарь, хэши, служебные сведения и известные шаблоны секретов. |

В исходных данных пропусков проверяемых представлений в условной выборке не
нашлось. Дополнительная проверка публичных индексов также не потребовала
менять их содержимое. Тесты воспроизводят эти случаи искусственно, чтобы
последующие сборки не скрывали подобные ошибки.

Суммы и границы остаются в [comparison.json](comparison.json), результаты
проверок архивов и индексов в [PUBLICATION-CHECK.json](PUBLICATION-CHECK.json).
