# Сравнение четырёх моделей FinBot

Основной документ - [REPORT.md](REPORT.md). В нём результаты GPT-4o mini,
GPT-5 nano, DeepSeek Flash и GPT-6 Luna High на общих 227 эпизодах, отдельная
серия Веры, проверки защитника, время и стоимость с оговорками об учёте.

| Путь | Содержимое |
|---|---|
| `tables/` | Эпизоды, общая выборка, метрики, 22 сочетания проверок, стоимость и время |
| `inputs/` | Сохранённые источники пересчёта, полные индексы запросов новых серий |
| `artifacts/` | Трассы, результаты инструментов, снимки БД, исходный код запусков и приёмка |
| `comparison.json` | Все агрегаты, определения метрик, интервалы Уилсона и ограничения |
| `REBUILD.json` | Полнота выборок и контрольные суммы входов и кода пересчёта |
| `PUBLICATION-CHECK.json` | Проверка архивов, запросов, SQLite и четырёх неизвестных исходов Luna |
| `REVIEW-NOTES.md` | Разбор замечаний к пересчёту и уточнения смысла стоимости и времени |

Из корня репозитория, Python 3 без дополнительных пакетов:

```sh
python3 experiments/control-placement/four-model-comparison/build_report.py
python3 experiments/control-placement/four-model-comparison/validate_bundle.py
python3 -m unittest discover -s experiments/control-placement/four-model-comparison -p test_report.py -v
```

Эти команды не импортируют FinBot и не делают запросов к моделям. Архивы можно
читать без распаковки; для восстановления структуры путей распаковывать из
корня репозитория. Сохранённые абсолютные пути внутри записей описывают исходное
окружение и не используются при пересчёте этого отчёта.

`prepare_bundle.py` нужен только для повторной подготовки публичной копии из
исходного локального дерева экспериментов. Для чтения и проверки опубликованных
результатов он не требуется. Манифест отдельно хранит контрольные суммы исходных
и публичных байтов. У журналов gzip изменён контейнер сжатия; содержимое записей
сохранено, кроме явно перечисленных служебных сведений внешнего аккаунта.
Одинаковая очистка и проверка применяется ко всем файлам `inputs/`, включая
сжатые индексы запросов и карты защитников. Приведённые в манифесте ревизии
описывают исходную упаковку данных; ребейз PR не меняет их происхождение.

В `guard-economics.csv` поле `query_duration_sum_s` содержит сумму длительностей
запросов. `input_votes_parallel_duration_s` оценивает одновременный запуск
входных голосов по максимуму длительностей. Это расчёт без очереди и накладных
расходов, а не замер задержки реальной блокировки. Для отсутствующих данных
сохраняется `null`; распределения содержат только известные значения.

Материалы Анастасии взяты из `research/control-placement` без правок. Их точная
ревизия указана в [манифесте](artifacts/manifest.json). В исходном тексте mini
есть расхождение о четырёх ложных отказах; сверка выбранного архива приведена
в отчёте и `tables/discrepancies.json`.
