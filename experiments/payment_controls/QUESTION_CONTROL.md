# Контроль формулировки вопроса

Этот дополнительный диагностический тест спроектирован после первичных 96 ответов. Первоначальные варианты одновременно отличались вопросом и подробностью значений ответов. Все расхождения с эталоном представляли собой дополнительные передачи на разбор.

Выбраны S02, S03, S07, S12 как случаи HOLD с передачей на разбор хотя бы в одном исходном варианте, S08 как честный контроль и S11 как контроль с отсутствующей информацией. На обеих моделях предъявить факты без резюме. Между условиями меняется только предложение вопроса. Три варианта A/B/C и их развёрнутые определения идентичны, одинаковы порядок вариантов, политика и остальные параметры. Для каждого провайдера 12 запросов. Исходы сравниваются попарно на документах. Если исходный разрыв исчезнет, результат будет совместим с объяснением через определения ответов. Влияние переименования опций отдельно не идентифицируется; новые случаи для переноса потребуются.
