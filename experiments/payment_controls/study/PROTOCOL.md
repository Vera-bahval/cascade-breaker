# Разработка защитника

До запросов зафиксированы 24 открытых семейства, обе независимые разметки и генератор. Каждый провайдер получает 120 запросов. Основная единица — семейство. Сравнить каждый вариант с facts попарно внутри семейства. При маскировании эталон берётся из поля masked. Порядок значений A/B/C вращается между семействами и сохраняется внутри семейства. Ошибка протокола ответа приводит к техническому REVIEW.

По каждому варианту публикуем точность, ошибочный ALLOW на BLOCK/REVIEW, ложную остановку на ALLOW, длительность и стоимость. Для отбора на следующую независимую серию сначала минимизируем ошибочные разрешения, затем ложные остановки, затем остальные ошибки, затем стоимость. Маскирование диагностическое. Для связки Jev → DeepSeek передаём запрос второй модели только при REVIEW первой. Это парная оценка на сохранённых ответах, без изменения поведения исполнителя.

Подтверждающая серия требует независимых калибровочных и тестовых семейств и успешной живой проверки каналов. Семь групп используют общий OFF, только код, одну модель и код с той же моделью на P2b и P4. Все недостигнутые точки сохраняются. Предел ложных остановок включает лишний итоговый REVIEW и техническую остановку. Перенос со своим оракулом проверяется отдельно на чате и онбординге.
