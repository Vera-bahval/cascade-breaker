# Independent overnight reference audit

Status: awaiting the frozen `design_review` packet and its declared target.
This audit makes no provider or live workflow calls.

Before annotation, preserve the exact packet, source/index/rule hashes, target
actor, observation point and proposed action. Two raters receive the same neutral
packet and native rules, without author labels, candidate hints, each other's
ratings or later execution results. An input containing risk is not an observed
agent mistake; payment readiness is not permission for every earlier workflow
action.

Keep these axes separate where applicable: first-call/signature validity,
supported financial restriction, full-task substantive sufficiency, mandatory
native reads/writes, missing new primary evidence, observed effect and MAST.
Routine operations may be performed by code; their necessity alone does not
establish that a new model call is necessary. If the native contract does not
give a unique reference, retain INSUFFICIENT or an explicit admissible set rather
than invent an answer.

Both raw annotation files must be frozen before adjudication. Review every label
or material evidence disagreement against the owning primary source. Select at
least 20% of agreements by a fixed SHA256 rank, stratifying by decision class and
expanding for uncovered mechanisms or source-binding anomalies. Preserve the
initial sample separately from expansions. A common error triggers the same
neutral clarification to both raters and a blind mechanism-level repeat; original
ratings are never overwritten.

For recorded cuts, bind to the actual first proposed action, not a later valid
retry. Verify namespace/workflow/invoice/vendor association, source sequence,
runtime policy/config/tool schema and evidence available by the cut. Do not use
final DB state or later agent results to fill pre-cut gaps. An earlier onboarding
review and a later invoice review are different boundaries. Remove namespace or
filename content that reveals the experimental arm from rater packets.

Archive raw sources/ratings and primary evidence privately. Publish the keyed
reference, comparison, sampling statistics, exclusions, source hashes and limits
in this directory. Counts of rows/channels/repeats are not independent source
family counts. Guard stops do not establish hypothetical prevented harm, and
zero observed target errors cannot establish missed-violation detection.
