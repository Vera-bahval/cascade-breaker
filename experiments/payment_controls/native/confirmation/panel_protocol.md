# Парная проверка решения на новых P1

Единица сравнения — первое предложение о передаче во Fraud, наблюдаемое в общей штатной ветке каждой из шести заранее зафиксированных задач. Если задача не дошла до P1, она остаётся в учёте живых запусков и не заполняется синтетическим снимком. Два контроля участвуют в парном диагностическом сравнении при достигнутом P1.

Обе модели получают один и тот же обезличенный префикс и вопрос нативного адаптера. Состояние представлено сериализованным JSON, как в зафиксированном адаптере. Карта букв постоянна: A = завершить без запрета Fraud, B = завершить с обоснованным запретом, C = передать во Fraud. До запросов проверяем привязку снимков, фиксируем хеши обоих тел и сверяем каждое дословное совпадение с прежними проверенными квитанциями. Ответы переносятся только при идентичном теле запроса для того же провайдера. Сопоставимость старых панелей по форме сама по себе не делает их повторами.

Для TH502@B заранее зафиксирован один дополнительный парный контраст, если независимый разбор подтвердит достижение P1 и возможность модели повлиять на решение. Меняется только вопрос: вместо прямого вопроса о завершении используется вопрос о достаточности свидетельств из архивной формы fact. Состояние, карта и критерии остаются теми же. Это сравнение формулировок решения о Fraud, а не отдельный вопрос с двоичным эталоном и не многошаговый каскад. При недостижении или неподтверждённой применимости замену не подбираем.

Разбор различает три действия и обязательность маршрута. Допустимая передача во Fraud не равна успешно автоматизированному завершению. Преждевременное закрытие на обязательных контролях учитывается отдельно от допустимого разрешения и необоснованного запрета. Рекомендации модели на контрольном снимке не меняют защищённый нативный маршрут. TH502@A и TH502@B образуют сравнение одного счёта при различном состоянии поставщика; их нельзя считать независимыми текстами. Маршрутные формулировки, уже присутствующие в одном и том же предложении оркестратора, остаются видимыми обеим моделям. Без отдельного вмешательства в текст префикса нельзя приписать расхождение таким словам.

Jev вызывается через официальный TypeSafe System One и сверяется с версией 1.14.0, DeepSeek Flash — через Eliza с выключенным reasoning и проверкой одного фактического запроса. Предельные новые расходы — 0,025 USD TypeSafe и 0,04 USD Eliza. Фактические квитанции сверяются со строками журнала. Запись с незакрытым резервом блокирует повтор.
