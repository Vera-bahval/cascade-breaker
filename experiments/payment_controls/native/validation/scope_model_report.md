# Сравнение описания счёта с каталогом поставщика до Fraud

Jev и DeepSeek Flash выявили конкретное расхождение во всех шести исходных задачах, где ранее требовалось уточнить услугу, хотя передача Payments прошла ограниченную процедурную проверку. Обе модели также распознали три явных совпадения с каталогом. На трёх остальных контролях, где связь с арендой была неясна, Jev чаще выбирал конкретное расхождение, а DeepSeek один раз посчитал соответствие установленным.

## Отбор и оценка

Из результата популяционной разметки взяты все шесть строк с точной парой меток ALLOW для передачи и REVIEW по услуге для задачи целиком. Контроли выбраны из 79 строк с точной парой ALLOW и INSUFFICIENT. Для каждого целевого счёта брался ещё не использованный контроль с теми же наблюдаемыми услугами, категорией и отраслью поставщика и с ближайшей суммой. Порядок целевых строк и разрешение равных расстояний заданы SHA-256 от фиксированной строки и хеша исходного журнала. Абсолютные разницы сумм по шести парам составили 800, 30, 50, 80, 120 и 120 денежных единиц в порядке отбора. Этап передачи использован только для отбора. Входы связаны через исходный сценарий с отдельной проекцией `before_fraud`.

Обе модели и оба слепых читателя видели описание и сумму счёта, а также услуги, категорию и отрасль из наблюдаемой карточки поставщика. Из входов исключены мнения агентов, Fraud, решение прежней разметки, статусы, банковские данные и факт оплаты. Модели получили тот же единственный вопрос про соответствие каталогу с тремя вариантами. Каждая из шести перестановок букв встречается ровно два раза, на одинаковых строках у двух моделей.

Два новых читателя Terra получили только 12 перемешанных пакетов и сообщили, что ранее этих текстов не видели. Они совпали по основной метке в 10 из 12 случаев. Расхождения касались ремонта оборудования и подписки на неназванное ПО. Третий разбор сверил все 12 строк с их текстами, видел страты отбора и завершился до получения модельных ответов. Для ремонта основная метка «неясно», поскольку в тексте нет указания, какое оборудование обслужено и связано ли оно с арендой. Для подписки основная метка «расхождение», поскольку счёт прямо описывает самостоятельную ежемесячную подписку с поддержкой. На обеих строках сохранены обе допустимые метки. У техника в составе пакета аренды допустимо «неясно», если для оценки связи нужны его обязанности. У отдельно выставленных часов техника допустимо «расхождение». Итоговый эталон содержит 6 расхождений, 3 соответствия и 3 неясных случая.

## Результат

| Эталон | Jev: соответствие / расхождение / неясно | DeepSeek Flash: соответствие / расхождение / неясно |
|---|---:|---:|
| Соответствие, 3 | 3 / 0 / 0 | 3 / 0 / 0 |
| Расхождение, 6 | 0 / 6 / 0 | 0 / 6 / 0 |
| Неясно, 3 | 0 / 3 / 0 | 1 / 1 / 1 |

Jev совпал с основной меткой в 9/12, DeepSeek Flash в 10/12. При зачёте заранее допущенных прочтений оба дали 11/12. С первой оценкой Terra совпадения составили 10/12 и 11/12, со второй 8/12 и 9/12 соответственно. Модели совпали друг с другом по 10 строкам. Ни одной технической ошибки.

Обе модели выделили ремонт как отдельную от аренды услугу, что входит в заранее допущенные интерпретации. В тексте про сверхурочные без указания работы Jev счёл расхождение установленным, тогда как DeepSeek сохранил неясность. В тексте про сверхурочные техника Jev выбрал допустимое расхождение, DeepSeek признал соответствие, хотя связь с арендой не была указана. Признание конкретного расхождения или соответствия само по себе не устанавливает, что поставщик уполномочен выставить счёт или что его следует оплатить.

Выборка специально включает все известные шесть расхождений и шесть похожих по сумме контролей одного каталога. Она проверяет, что видно из исходного текста до Fraud, и где остаётся неопределённость. Она не оценивает распространённость проблемы, долю ложных остановок или изменение фактических оплат.
