# Архивная проверка недостающего состояния P4

Первичная выборка — 1 261 отложенное предложение P4 со строгой меткой INSUFFICIENT. Строгая метка относится к исходному пакету защитника до действия. Колонка as_of_label относится к исторической оценке с дополнительным доступом адаптера к состоянию на момент предложения.

| Источник | В выборке | ALLOW со снимком | REVIEW со снимком | Недостаточно данных |
|---|---:|---:|---:|---:|
| Штатные каналы | 448 | 51 | 397 | 0 |
| Штатные core-повторы | 272 | 30 | 242 | 0 |
| Основная нативная выборка | 207 | 0 | 0 | 207 |
| Дополнительные нативные запуски | 334 | 0 | 0 | 334 |
| Всего | 1 261 | 81 | 639 | 541 |

81 ALLOW получен по 66 разным исходным обязательствам. У 720 штатных предложений подтверждён снимок единственного связанного поставщика до триггера, в котором исчерпан список транзакций с лимитом 50. Единственная связанная трасса подтверждает отсутствие более раннего исполнения перевода по этому счёту. На момент всех 720 предложений подтверждено ноль завершённых переводов по счёту. Фактический запрос Payments включал TaxCalc и условие проверки налога при наличии инструмента.

У 520 предложений определения инструментов присутствуют в собственной записи. Для оставшихся 200 запрос содержит имена инструментов и хеш определений. В другом проверенном члене того же архива найдены определения с совпадающим хешем. Список их имён совпадает с записанным списком фактического запроса. Хеш журнала-свидетеля указан в source_recovery.jsonl.

У всех 541 нативных предложений сохранилась итоговая выгрузка БД, у 177 также сохранилась пара SQLite и JSON итоговой БД. Журнал и метаданные известных артефактов не дают исчерпанного реестра переводов на момент действия. До границы не найдено ни вызовов чтения истории переводов, ни завершённых квитанций. Их исход — INSUFFICIENT и в расширенном просмотре.

Точную разметку ранее проверенного набора из 48 предложений переиспользовали по совпадению пакетов и хешам квитанции. В целевой выборке присутствуют 46 из 48. Ещё два имели строгую метку REVIEW и входят в аналитическую панель из 722 предложений. Два Terra 6.1 независимо прочли каждый из 674 новых пакетов. Метки совпали. Третий оценщик Sol независимо прочёл 136 согласованных пакетов, отобранных фиксированным хеш-порядком внутри меток каждой партии. Сверка отдельно выполнена для 12 предложений из шести известных калибровочных семейств. Калибровка содержит 6 ALLOW и 6 REVIEW, с независимой проверкой 4 согласованных решений.

Новые REVIEW в этом срезе относятся к историческому требованию выполнить проверку TaxCalc. Они характеризуют исторический контракт и доступные предшествующие результаты. Связь налогового результата с текущим счётом применяется по правилам исходной проекции. Юридическая применимость выбранной налоговой категории и состояние реализации налоговой проверки в новом исполнителе требуют отдельной оценки.

- recovery_table.jsonl содержит одно решение на каждое из 1 261 предложений, координаты источников и обе области видимости.
- summary.json содержит счётчики и хеши выдачи. Квитанции партий связывают слепые входы, A/B, третью оценку и итог.
- verified_action_packets.jsonl и verified_action_gold.jsonl содержат согласованную панель в формате исходного sensitivity. Для калибровки отдельно применяются blind_dev.jsonl и gold_dev.jsonl.

```sh
python3 -m experiments.payment_controls.native.final_study.finale.p4.adjudicate finalize dev
python3 -m experiments.payment_controls.native.final_study.finale.p4.adjudicate publish
```
