### Воспроизведение

Из корня checkout выполните команды ниже с Python 3. Распаковка идёт в отдельный каталог. Ключи и вызовы API не требуются.

```sh
OUT=$(mktemp -d)
unzip -q experiments/payment_controls/native/final_study/finale/study-evidence.zip -d "$OUT"
(cd "$OUT" && shasum -a 256 -c MANIFEST.sha256)
cd "$OUT"/experiments/payment_controls/native/final_study/finale
python3 technical.py
python3 publish.py
python3 correction/release_check.py
```
