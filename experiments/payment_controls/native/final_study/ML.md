# Проверка локальных моделей FinBot

В этой серии целевая переменная устанавливает, требует ли наблюдавшееся следующее действие вмешательства по действовавшей на этом шаге политике. Для P1 оценивается передача поручения Payments, для P4 — конкретное предложение перевода. Неопределённые строки остаются в реестре, но не входят в расчёт Brier, log loss и частот ошибок. Модель не использует сведения о последующем исполнении. Успешное предсказание вмешательства само по себе не устанавливает предотвращённый ущерб.

## Сравнение в финальной серии

Три варианта получают одни и те же разрешённые по разметке состояния с сохранённым официальным вектором Jev.

- **LR по фактам.** L2-регуляризация с фиксированным `C=1`. Признаки — состояние счёта и поставщика, риск и доверие к поставщику, отношения суммы, счёта получателя, ссылки и поставщика, валидность метода, зафиксированные до действия переводы, флаги, наличие привязанного Fraud и наблюдавшаяся налоговая проверка. Значения отношений допускают неизвестность. Идентификаторы, суммы как числа, времена событий, полный текст и исход не являются признаками.
- **Jev.** Скаляр `P(BLOCK) + P(REVIEW)` из сохранённого официального ответа. Его Brier и log loss показывают пригодность этого скаляра для бинарного эталона исследования.
- **LR по фактам и Jev.** Та же LR с тремя вероятностями `ALLOW`, `BLOCK` и `REVIEW`. Линейная модель может изменить интерпретацию уверенности, при этом каждый её обучающий пример требует сохранённого ответа Jev.

Обучение по архивным группам даёт одинаковый суммарный вес каждой группе в FIT. Для основного сравнения используется вариант Jev, выбранный на development для живой ветки C с доступным Fraud-контекстом, с такими же группами FIT и CAL для LR. В архивном holdout исключаются все группы, участвовавшие в выборе Jev, включая другие траектории из тех же групп. Архивную групповую кросс-валидацию учитываем отдельно как ретроспективную диагностику. Внутри каждого разбиения FIT, CAL и тест имеют непересекающиеся группы. P1 и P4 считаются отдельно. Строки без полного вектора показываются в охвате и могут участвовать в отдельной диагностике LR по всем определённым меткам.

Порог берётся по CAL. Группа с хотя бы одной ложной остановкой получает единицу при расчёте односторонней точной 95%-ной верхней границы Клоппера–Пирсона. Если граница ≤5% недостижима, диагностический порог сначала минимизирует наблюдавшиеся ложные остановки, затем максимизирует обнаружения. При нуле ошибочных групп для границы 5% нужны как минимум 59 независимых безопасных групп. Значение на CAL используется для выбора порога. Оценка на отложенной выборке фиксируется отдельно. Групповая граница относится к групповой частоте и требует допущения об независимости групп. В каждой группе могут быть несколько возможностей остановки.

В JSON сохранены Brier, log loss и пять интервалов надёжности с числом действий, средней вероятностью и наблюдаемой долей вмешательств, а также ложные остановки, обнаружения и точные совпадения проекций с FIT/CAL. 95%-ные парные интервалы для разницы Brier и log loss получены бутстрэпом целых групп с фиксированными предсказаниями. Они описывают изменение состава отложенной выборки. Варьирование обучения и выбор порога в интервал не входят. Чувствительность на проекциях, которые отсутствовали в FIT и CAL, считается на общих ID трёх методов. Совпадение проекции означает ограниченную новизну представления, даже при разных исходных сценариях.

## Проверка входных проекций

В версии `literal-v3` проверены 681 исходная граница из 359 траекторий. В каждом пакете проверенные факты с номерами событий предшествуют предложению. У 359 P1 из 195 канонических групп есть 17 различных структурных векторов LR, у 322 P4 из 185 групп — 21. Наиболее частый вектор встречается в 236 строках P1 и 221 строке P4. Совпадение через границу групп есть у 353 P1 и 307 P4. Эти числа относятся к компактному набору признаков LR. Полные пакеты Jev могут различаться формулировкой поручения, содержанием ответа Fraud и другими сведениями. [Инвентаризация](ml_archive_inventory.json)

## Воспроизведение

Из корня checkout `cascade-breaker-publication`. Для исторической части требуются сохранённые локальные результаты SecJev соседнего проекта и версии библиотек из сохранённых CatBoost-артефактов.

```sh
ML=experiments/payment_controls/native/final_study
PY=../../experiments/local_guards/.venv/bin/python
"$PY" "$ML/ml_history.py" --replay-secjev | diff -u "$ML/ml_history.json" -
"$PY" "$ML/ml_study.py" --inventory-only
"$PY" "$ML/ml_study.py" --self-check
```

В первом проходе после релиза официальных ответов обучающие пакеты, соответствия, эталон и сохранённый wire freeze передаются через `--packets`, `--mapping`, `--groups`, `--gold` и `--wire-freeze`. Команда `--panel development --selection … --freeze-models` фиксирует коэффициенты и пороги до чтения архивных предсказаний. Команда с `--panel archive --selection … --read-freeze …` читает этот артефакт, вычисляет предсказания всех трёх методов для одних и тех же строк и сохраняет групповые разбиения, вероятности и метрики. Для нескольких отдельно замороженных архивных волн `ml_archive.py --waves …` связывает результаты с выпущенными wire manifest и проверенной разметкой. В режиме `--facts-only` внешний вектор и wire freeze не нужны.

## Диагностика на development до официальных ответов Jev

В 24 размеченных P1 по одному действию на группу, 12 требуют вмешательства и 12 допускают продолжение. В кросс-валидации по пяти групповым разбиениям LR по фактам обнаружила 10 из 12 вмешательств, ложных остановок было 0 из 12. Brier — 0,03691, log loss — 0,20546. Порог каждого разбиения подбирался по отдельной CAL, ни в одном разбиении верхняя групповая граница не достигла 5%. Этот набор участвует в выборе дизайна, а его сбалансированный отбор не отражает распространённость вмешательств в архиве. На 24 P4 имеется 12 положительных и 12 неопределённых меток. Для обучения бинарной LR P4 по этому набору нет подтверждённых отрицательных примеров. ## Заморозка перед оценкой архива

Ветка C использует P1, вопрос о конкретном незакрытом условии и доступный привязанный ответ Fraud. Для всех трёх методов заморожены одни и те же 12 FIT и 12 CAL. Каждая часть содержит шесть разрешённых действий и шесть действий, требующих вмешательства. В CAL все три метода отметили 6/6 необходимых вмешательств и 0/6 ошибочных остановок. Односторонняя верхняя граница на уровне групп — 39,30%, поэтому пороги остаются исследовательскими.

| Метод | Порог для вмешательства |
|---|---:|
| LR по фактам | 0,7157712893 |
| Jev | 0,9700000000 |
| LR по фактам и Jev | 0,7143438105 |

Порог применяется со знаком `>=`. Заморозка связывает группы, исходный эталон, подготовленный wire freeze и сохранённые векторы. [Коэффициенты и пороги](ml_development_freeze.json)

## Первая отложенная архивная серия

В серии из 46 независимо проверенных действий сравнительная таблица использует все 24 определённых P1 из 20 канонических групп. Ни одна группа не участвовала в development. В P1 есть четыре обязательных вмешательства и 20 разрешённых действий. Из 22 P4 эталон определяет пять необходимых вмешательств и оставляет 17 случаев неопределёнными. Подтверждённых разрешённых P4 в этой серии нет, поэтому сравнение P4 по ложным остановкам и обучение бинарных моделей для P4 не проведены.

| Метод с замороженным порогом | Обнаружено | Ложные остановки | Brier ↓ | Log loss ↓ |
|---|---:|---:|---:|---:|
| LR по фактам | 4/4 | 0/20 | 0,02568 | 0,17400 |
| Jev | 4/4 | 0/20 | 0,22281 | 0,61205 |
| LR по фактам и Jev | 4/4 | 0/20 | 0,02164 | 0,15802 |

Все три метода приняли одинаковые решения. Верхняя односторонняя граница по 19 группам с безопасным действием составляет 14,59%. При повторном обучении и выборе порога внутри первой архивной серии каждый метод обнаруживает 3/4 вмешательств при 0/20 ложных остановок. Эта проверка описывает устойчивость к разбиению именно данного корпуса.

В 20 разрешённых P1 средняя вероятность LR по фактам составляет 0,166, у LR с Jev — 0,153. У самого Jev 4 из 20 безопасных P1 попали в интервал [0,2–0,4), 13 в [0,4–0,6), три в [0,6–0,8). Все четыре нуждающихся во вмешательстве P1 попали в диапазон [0,8–1] у каждого метода. На разрешённых действиях добавление Jev немного уменьшает ошибку вероятности относительно LR по фактам. Для парной разницы «LR с Jev минус LR по фактам» интервалы бутстрэпа групп равны от −0,00486 до −0,00337 для Brier и от −0,01916 до −0,01330 для log loss. Это изменение вероятностей на одном наборе с фиксированными моделями.

У 20 из 24 тестовых P1 структуры признаков LR в точности встречались в FIT или CAL, хотя группы различались. Четыре строки с новой структурной проекцией включают два безопасных действия и два вмешательства. Все три метода верно классифицировали эти четыре строки. Масштаб этого поднабора ограничивает перенос вывода на новые сочетания фактов. Прямые запросы для 24 использованных векторов Jev стоили $0,001305066, медиана RPC составила 0,229 с. Локальная LR по фактам не требует внешней оценки вектора. В этой серии доплата за Jev изменила вероятности при одинаковых решениях. ## Накопленный отложенный архив

В 10 независимо проверенных сериях 563 действий. Основное сравнение использует 296 P1 из 169 канонических групп. В них 86 вмешательств и 210 разрешённых действий. В P1 остаётся 2 неопределённых действий. 265 P4 содержат 58 нуждающихся во вмешательстве и 207 неопределённых. У разрешённых P4 в этих сериях нет определённого эталона. Коэффициенты и пороги были заморожены до оценки. Группы сверены с реестром обязательств, включая разные названия одного сценария в архивных источниках.

| Метод | Обнаружено | Ложные остановки | Brier ↓ | Log loss ↓ | Групповая верхняя граница 95% |
|---|---:|---:|---:|---:|---:|
| LR по фактам | 84/86 | 4/210 | 0,04243 | 0,21725 | 6,60% |
| Jev | 77/86 | 3/210 | 0,18158 | 0,83356 | 5,60% |
| LR по фактам и Jev | 80/86 | 3/210 | 0,03913 | 0,20429 | 5,60% |

По сравнению с LR по фактам комбинированная LR пропустила 4 дополнительных вмешательства и выявила 0 ранее пропущенных. Для безопасных действий она сняла 1 ложных остановок и добавила 0. Верхняя граница по 136 группам с разрешённым действием превышает 5% у каждого метода.

Для разницы «LR с Jev минус LR по фактам» групповой интервал Brier составляет от −0,00402 до −0,00249, log loss — от −0,01575 до −0,00973. Комбинированная модель в среднем лучше оценивает вероятность. Число обнаруженных вмешательств и ложных остановок следует оценивать отдельно по зафиксированным порогам.

255 из 296 структурных векторов совпали с FIT или CAL. На 41 строках с новыми векторами из 20 групп LR по фактам обнаружила 29/29 вмешательств и дала 1/12 ложных остановок. У комбинированной LR соответственно 29/29 и 0/12. Brier по фактам составил 0,05288, с дополнительными вероятностями — 0,05164. 296 использованных ответов Jev стоили $0.016494576. ## P4 с проверенной доступностью дополнительных сведений

Отдельная оценка включает 48 реальных предложений перевода из 24 удержанных обязательств. Для каждого обязательства заранее выбраны пары с наблюдавшимся успешным TaxCalc и без него. В этой постановке защитнику дополнительно доступны подтверждённая область прошлых переводов и доступность TaxCalc в исходном запросе. Независимый эталон содержит 24 ALLOW и 24 REVIEW. Распределение отражает парный отбор, а прогон описывает именно такую видимость данных.

| Метод | Обнаружено REVIEW | Ложные остановки | Brier ↓ | Log loss ↓ |
|---|---:|---:|---:|---:|
| Код с проверкой условий | 24/24 | 0/24 | — | — |
| LR по фактам | 24/24 | 0/24 | 0,01760 | 0,14229 |
| Jev с видимостью адаптера | 21/24 | 0/24 | 0,01998 | 0,14582 |
| LR по фактам и Jev | 21/24 | 0/24 | 0,01121 | 0,11174 |

Код проверял связанный перевод, корректность операции, Fraud-ограничения и требуемый успешный TaxCalc. Для трёх вероятностных вариантов пороги пересчитаны во внутренней CAL каждого архивного разбиения. Обе строки пары остаются в одной группе. Код фиксирован до просмотра официальных ответов. Для 24 безопасных групп без ложной остановки групповая верхняя 95%-ная граница составляет 11,73%. Все структурные векторы теста встречались в FIT или CAL. Добавление Jev уменьшает Brier на этих структурно повторяющихся парах, при этом пропускает три REVIEW. Парный бутстрэп для разницы Brier даёт интервал от −0,00674 до −0,00603.

Остальные сравнения Jev показывают эффект иной видимости при фиксированном способе принятия решения. С дополнительным контекстом argmax правильно классифицирует 48/48. С обычным префиксом argmax возвращает ALLOW для всех 48. При переносе порога 0,97, замороженного на P1, ни один из 24 эталонных REVIEW не был остановлен. Ни кросс-валидация P4, ни argmax не меняют ранее замороженное решение для P1.
