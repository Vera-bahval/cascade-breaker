# Следом за каждым предложением FinStripe

Проверены все 542 строки прежнего исследования no-LLM. Для каждой восстановлен **результат именно предложенного вызова**. Совпали контрольная сумма исходного архива, хеш журнала эпизода и положение события. В журнале вызов сопоставлен с ответом по инструменту и аргументам. У успешной квитанции проверены идентификатор перевода, сумма, получатель, номер счёта и валюта. Если аргумент валюты опущен, в этих записях квитанция показывает штатный USD. Проверка указывает на эффект в симуляторе. Она не приравнивает его к реальному банковскому списанию, законности сделки или независимой экспертизе участника. Единственная остановка видна в журнале старого защитника между предложением перевода и завершением задачи. Для других 541 предложений найден ответ FinStripe с совпадающими полями. В архиве отбирались прогоны, уже достигшие предложения перевода. 319/542 не оценивает вероятность ошибиться при получении обычного нового счёта. Для этого нужна выборка с момента поступления задачи.

Признаки перекрываются. Оба расхождения банковского счёта относятся к двум старым стрессовым прогонам одного происхождения. В обоих также отличается сумма. По ним есть подтверждённый эффект на неверных реквизитах, но нет нового чистого сравнения, которое выделяло бы ошибку получателя при прочих равных. Срез из 1 822 предложений без старого формата и отдельный реестр на 542 состояния имеют разные составы. Отрицательный результат одного среза нельзя переносить на другой. Поля ID поставщика/счёта и номера в сопоставимых парах запроса и текущей записи не показали расхождений. Это слабее проверки принадлежности счёта реальному хозяйственному обязательству. [Предыдущая карта механизмов](../mechanism_study/coverage.md)

Среди оплат при pending есть обычные TH504 и TH505. Две записи TH504 с одним исходным обязательством считаются одним семейством. Для TH504 найден отдельный вариант с тем же счётом и активным поставщиком. Три оплаты при processing сосредоточены в одной группе на 12 000 USD, где одновременно применимо ограничение суммы. Эффект самостоятельного нарушения статуса processing по этому сравнению не выделяется.

Прежний флаг удержания — поле старой проекции. У 26 из 199 предложений с этим флагом содержательная разметка была ALLOW, у 18 — INSUFFICIENT. Поэтому правильность остановки здесь определяется областью правила, источником/объектом удержания и допустимостью ближайшего действия. Сходно, 528 прежних переводов без подтверждённой внешней проверки налога нельзя считать 528 неверными налоговыми суммами. Сейчас налог сверяет сам платёжный инструмент. Отдельные серии проверяли квалифицированный HOLD по тому же счёту и переплату с документированным значением principal.
