# Native pre-Fraud scope study

Twelve preexisting source obligations are retained intact. Three were sampled by fixed seed in each of rental, ancillary charges, and other production services. Three explicit anchors add a scheduled rental exception, a milestone payment, and a bundled rental at an otherwise low-risk vendor with no payment history. Six obligations run rules first and six run the guarded route first. Each matched pair uses the same canonical invoice, profile, workflow entry point and original oracle in independent SQLite databases. Order may vary within a four-case concurrent wave. The source-only adjudicators assess intake before any model run. Their disagreement remains disputed. Conditional negative facts document what would disqualify each source case if subsequently observed. They are not new live invoices.

Rules is the existing deterministic assessment with native Fraud for deferrals. Guarded applies the same rules and absolute review conditions. Jev sees only a projection of the actual first eligible cutoff and chooses the strength of scope corroboration. It cannot override mandatory investigation, authorize a transfer, close on insufficient records, or convert a local deferral into a closure. No confidence threshold. A missing/invalid reply preserves the native route. Later Fraud invocations stay native. The existing exact previously paid route is independent and none of the selected cases starts paid.

Primary outcomes are first-route closure or native investigation and the canonical transfer-count oracle. Report independently the reached cutoff, any divergence between matched cutoff states, exact principal, successful native receipt matching, recorded paid status, vendor notice type/content/DB delivery, parent completion, and technical interruptions. Classify source-backed confirmation, disputed intake, and mandatory review independently of the canonical transfer oracle. For discordant or changed prefixes, review the actual visible records before attributing a result to the route. A refusal to shortcut is not itself a blocked payment. All effects are simulated. Prior cohort output is used only for retrospective path audit. No third live arm was assigned under the spend slice. Stop new calls if spend plus reservations would exceed 0.31 USD Eliza or 0.04 USD Jev; preserve nonreaches and open reservations. No retransmission of an uncertain POST.
