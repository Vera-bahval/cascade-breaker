## Воспроизведение

Python3.13.15,numpy2.5.4,SQLite3.53.1; окружение то же, что [legacy176](../local_guards_legacy176/environment.json). Исходные пути/хеши находятся в inputmanifest; raw_episodes проверяет архивы и журналы по collector-manifest. Для повторной подготовки исходные локальные архивы обязательны; сохранённые ответы/входы позволяют пересчитать качество без моделей.

```sh
python -m unittest experiments.local_guards_archive_profile.test_profile -q
python -m experiments.local_guards_archive_profile.audit
python -m experiments.local_guards_archive_profile.evaluate
python -m experiments.local_guards_archive_profile.render
python -m experiments.local_guards_archive_profile.update_report
python -m experiments.local_guards_archive_profile.manifest --check
```

Для независимого нового deterministic-run использовать отдельную копию, `prepare`, независимый exactcommit/inputhash допуск, затем `execute` и `execute --benchmark`. Эти команды отказываются перезаписывать результаты. Никаких LLM/API/SecJev вызовов, новых MLпредсказаний или обучения нет. Денежная стоимость локальных вычислений не выдумывается.
