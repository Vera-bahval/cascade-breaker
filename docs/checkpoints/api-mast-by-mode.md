# Каскады по режимам MAST: конверсия и лучший барьер

gpt-5-nano, без наших проверок, 96 прогонов через API (чат и онбординг). Считаются только N-варианты (вход ведёт к вреду);
прогоны, где счёт оплачен ещё в подготовке, и сломанные прогоны исключены. Сценарий с двумя метками MAST входит в обе строки.

**Как читать.** Каждая колонка показывает долю N-прогонов, дошедших до этой стадии: прошёл чат (чат передал запрос
дальше), прошёл агентов (агент счетов или онбординг не остановил), вред (каскад дошёл до вреда). Лучший барьер это
агент, который чаще всего обрывал каскад; это его собственное решение, а не наша проверка.
